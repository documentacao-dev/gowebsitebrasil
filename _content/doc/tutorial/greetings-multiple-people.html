Nas últimas alterações que você vai fazer no código do seu módulo, você vai adicionar suporte para obter saudações para várias pessoas em uma única requisição. Em outras palavras, você vai tratar uma entrada com múltiplos valores e, em seguida, associar os valores dessa entrada a uma saída com múltiplos valores. Para isso, você vai precisar passar um conjunto de nomes para uma função que consiga retornar uma saudação para cada um deles.

Observação: Este tópico faz parte de um tutorial em várias partes que começa com Criar um módulo Go.

Mas há um porém. Trocar o parâmetro da função Hello de um único nome por um conjunto de nomes mudaria a assinatura da função. Se você já tivesse publicado o módulo example.com/greetings e os usuários já tivessem escrito código chamando Hello, essa mudança quebraria os programas deles.

Nesta situação, uma escolha melhor é escrever uma nova função com outro nome. A nova função vai receber múltiplos parâmetros. Assim, a função antiga é preservada para manter a compatibilidade com versões anteriores.

  1. Em greetings/greetings.go, altere o seu código para que fique como o exemplo a seguir. 
    package greetings

import (
    "errors"
    "fmt"
    "math/rand"
)

// Hello returns a greeting for the named person.
func Hello(name string) (string, error) {
    // If no name was given, return an error with a message.
    if name == "" {
        return name, errors.New("empty name")
    }
    // Create a message using a random format.
    message := fmt.Sprintf(randomFormat(), name)
    return message, nil
}

// Hellos returns a map that associates each of the named people
// with a greeting message.
func Hellos(names []string) (map[string]string, error) {
    // A map to associate names with messages.
    messages := make(map[string]string)
    // Loop through the received slice of names, calling
    // the Hello function to get a message for each name.
    for _, name := range names {
        message, err := Hello(name)
        if err != nil {
            return nil, err
        }
        // In the map, associate the retrieved message with
        // the name.
        messages[name] = message
    }
    return messages, nil
}

// randomFormat returns one of a set of greeting messages. The returned
// message is selected at random.
func randomFormat() string {
    // A slice of message formats.
    formats := []string{
        "Hi, %v. Welcome!",
        "Great to see you, %v!",
        "Hail, %v! Well met!",
    }

    // Return one of the message formats selected at random.
    return formats[rand.Intn(len(formats))]
}

    Neste código, você:

    • Adiciona uma função Hellos cujo parâmetro é um slice de nomes em vez de um único nome. Além disso, você altera um dos tipos de retorno dela de string para map, para poder retornar nomes associados a mensagens de saudação.
    • Faz a nova função Hellos chamar a função existente Hello. Isso ajuda a reduzir a duplicação e, ao mesmo tempo, mantém as duas funções no lugar.
    • Cria um map messages para associar cada um dos nomes recebidos (como chave) a uma mensagem gerada (como valor). Em Go, você inicializa um map com a seguinte sintaxe: make(map[key-type]value-type). Você faz a função Hellos retornar esse map para quem a chamou. Para saber mais sobre maps, veja Maps em Go na prática no blog do Go.
    • Percorre os nomes que a função recebeu, verificando se cada um tem um valor não vazio, e então associa uma mensagem a cada um. Neste loop for, range retorna dois valores: o índice do item atual no loop e uma cópia do valor do item. Você não precisa do índice, então usa o identificador em branco do Go (um sublinhado) para ignorá-lo. Para saber mais, veja O identificador em branco em Effective Go.
  2. No código de chamada em hello/hello.go, passe um slice de nomes e, em seguida, imprima o conteúdo do map de nomes/mensagens que você recebe de volta.

    Em hello.go, altere o seu código para que fique como o exemplo a seguir. 

    package main

import (
    "fmt"
    "log"

    "example.com/greetings"
)

func main() {
    // Set properties of the predefined Logger, including
    // the log entry prefix and a flag to disable printing
    // the time, source file, and line number.
    log.SetPrefix("greetings: ")
    log.SetFlags(0)

    // A slice of names.
    names := []string{"Gladys", "Samantha", "Darrin"}

    // Request greeting messages for the names.
    messages, err := greetings.Hellos(names)
    if err != nil {
        log.Fatal(err)
    }
    // If no error was returned, print the returned map of
    // messages to the console.
    fmt.Println(messages)
}

    Com essas alterações, você:

    • Cria uma variável names como um tipo slice que armazena três nomes.
    • Passa a variável names como argumento para a função Hellos.
  3. Na linha de comando, vá para o diretório que contém hello/hello.go e use go run para confirmar que o código funciona.

    A saída deve ser uma representação em string do map que associa nomes a mensagens, algo como o exemplo a seguir: 

    $ go run .
map[Darrin:Hail, Darrin! Well met! Gladys:Hi, Gladys. Welcome! Samantha:Hail, Samantha! Well met!]

Este tópico apresentou maps para representar pares nome/valor. Ele também apresentou a ideia de preservar a compatibilidade com versões anteriores, implementando uma nova função para funcionalidades novas ou alteradas em um módulo. Para saber mais sobre compatibilidade com versões anteriores, veja Mantendo seus módulos compatíveis.
