Tratar erros é um recurso essencial de código sólido. Nesta seção, você vai adicionar um pouco de código para retornar um erro do módulo greetings e, em seguida, tratá-lo no código que faz a chamada.

Nota: Este tópico faz parte de um tutorial em várias partes que começa com Criar um módulo Go.
  1. Em greetings/greetings.go, adicione o código destacado abaixo.

    Não faz sentido enviar uma saudação de volta se você não sabe quem cumprimentar. Retorne um erro para quem chamou a função se o nome estiver vazio. Copie o código a seguir para greetings.go e salve o arquivo. 

    package greetings

import (
    "errors"
    "fmt"
)

// Hello returns a greeting for the named person.
func Hello(name string) (string, error) {
    // If no name was given, return an error with a message.
    if name == "" {
        return "", errors.New("empty name")
    }

    // If a name was received, return a value that embeds the name
    // in a greeting message.
    message := fmt.Sprintf("Hi, %v. Welcome!", name)
    return message, nil
}

    Neste código, você:

    • Altera a função para que ela retorne dois valores: uma string e um error. Quem chama vai verificar o segundo valor para saber se ocorreu um erro. (Qualquer função em Go pode retornar vários valores. Para saber mais, veja Effective Go.)
    • Importa o pacote errors da biblioteca padrão do Go para poder usar a sua função errors.New.
    • Adiciona uma instrução if para verificar uma requisição inválida (uma string vazia onde deveria estar o nome) e retornar um erro se a requisição for inválida. A função errors.New retorna um error com a sua mensagem dentro.
    • Adiciona nil (que significa nenhum erro) como segundo valor no retorno de sucesso. Assim, quem chama pode ver que a função teve sucesso.
  2. No seu arquivo hello/hello.go, trate o erro agora retornado pela função Hello, junto com o valor que não é erro.

    Cole o código a seguir em hello.go. 

    package main

import (
    "fmt"
    "log"

    "example.com/greetings"
)

func main() {
    // Set properties of the predefined Logger, including
    // the log entry prefix and a flag to disable printing
    // the time, source file, and line number.
    log.SetPrefix("greetings: ")
    log.SetFlags(0)

    // Request a greeting message.
    message, err := greetings.Hello("")
    // If an error was returned, print it to the console and
    // exit the program.
    if err != nil {
        log.Fatal(err)
    }

    // If no error was returned, print the returned message
    // to the console.
    fmt.Println(message)
}

    Neste código, você:

    • Configura o pacote log para imprimir o nome do comando ("greetings: ") no início das suas mensagens de log, sem data e hora nem informações de arquivo-fonte.
    • Atribui os dois valores retornados por Hello, incluindo o error, a variáveis.
    • Troca o argumento de Hello do nome da Gladys por uma string vazia, para que você possa testar o seu código de tratamento de erros.
    • Verifica se há um valor error diferente de nil. Neste caso, não faz sentido continuar.
    • Usa as funções do pacote log da biblioteca padrão para exibir informações de erro. Se houver um erro, você usa a função Fatal do pacote log para imprimir o erro e encerrar o programa.
  3. Na linha de comando, no diretório hello, execute o hello.go para confirmar que o código funciona.

    Agora que você está passando um nome vazio, vai obter um erro. 

    $ go run .
greetings: empty name
exit status 1

Esse é o tratamento de erros comum em Go: retornar um erro como valor para que quem chama possa verificá-lo.
