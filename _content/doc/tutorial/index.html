Se você é novo em alguma parte do Go, dê uma olhada nos tutoriais listados abaixo.

Se você ainda não instalou o Go, veja Baixar e instalar.

Tutorial Descrição
Primeiros passos Diga Olá, Mundo com Go.
Criar um módulo Um tutorial em várias partes que apresenta recursos comuns de linguagens de programação sob a perspectiva do Go.
Primeiros passos com workspaces de múltiplos módulos Apresenta o básico de criar e usar workspaces de múltiplos módulos em Go. Workspaces de múltiplos módulos são úteis para fazer alterações em vários módulos.
Trabalhando com JSON Apresenta o básico de trabalhar com JSON usando a biblioteca padrão.
Acessando um banco de dados relacional Apresenta o básico de acesso a um banco de dados usando a biblioteca padrão.
Desenvolvendo uma API RESTful com Go e Gin Apresenta o básico de escrever uma API de serviço web RESTful com Go e o framework web Gin.
Primeiros passos com generics Apresenta o básico de generics em Go. Com generics, você pode declarar e usar funções ou tipos escritos para funcionar com qualquer um de um conjunto de tipos fornecidos pelo código chamador.
Primeiros passos com fuzzing Apresenta o básico de fuzzing em Go. O fuzzing pode gerar entradas para os seus testes que podem pegar casos de borda e problemas de segurança que você talvez tenha deixado passar.
Primeiros passos com govulncheck Apresenta como encontrar e corrigir vulnerabilidades com o govulncheck. O govulncheck informa vulnerabilidades conhecidas que afetam o código Go.
Encontrar e corrigir dependências vulneráveis com VS Code Go Apresenta como encontrar e corrigir dependências vulneráveis diretamente da sua IDE com VS Code Go e Vim.
Um Tour pelo Go Uma introdução interativa ao Go: sintaxe básica e estruturas de dados; métodos e interfaces; e as primitivas de concorrência do Go.
