Neste tutorial, você terá uma breve introdução à programação em Go. Ao longo do caminho, você vai:

  • Instalar o Go (se ainda não tiver instalado).
  • Escrever um código simples de "Hello, world".
  • Usar o comando go para executar seu código.
  • Usar a ferramenta de descoberta de pacotes do Go para encontrar pacotes que você pode usar no seu próprio código.
  • Chamar funções de um módulo externo.
Nota: Para outros tutoriais, veja Tutoriais.

Pré-requisitos

  • Alguma experiência em programação. O código aqui é bem simples, mas ajuda saber um pouco sobre funções.
  • Uma ferramenta para editar seu código. Qualquer editor de texto que você tenha vai funcionar bem. A maioria dos editores tem bom suporte a Go. Os mais populares são VSCode (gratuito), GoLand (pago) e Vim (gratuito).
  • Um terminal de comandos. O Go funciona bem em qualquer terminal no Linux e no Mac, e no PowerShell ou cmd no Windows.

Instalar o Go

Basta seguir os passos de Baixar e instalar.

Escrever algum código

Comece com o Hello, World.

  1. Abra um prompt de comando e use cd para ir até o seu diretório home.

    No Linux ou Mac: 

    cd

    No Windows: 

    cd %HOMEPATH%
  2. Crie um diretório hello para o seu primeiro código-fonte em Go.

    Por exemplo, use os seguintes comandos: 

    mkdir hello
cd hello
  3. Ative o rastreamento de dependências do seu código.

    Quando o seu código importa pacotes contidos em outros módulos, você gerencia essas dependências pelo próprio módulo do seu código. Esse módulo é definido por um arquivo go.mod, que rastreia os módulos que fornecem esses pacotes. Esse arquivo go.mod fica junto com o seu código, inclusive no seu repositório de código-fonte.

    Para ativar o rastreamento de dependências do seu código criando um arquivo go.mod, execute o comando go mod init, informando o nome do módulo em que o seu código vai ficar. Esse nome é o caminho do módulo (module path).

    No desenvolvimento real, o caminho do módulo normalmente é o local do repositório onde o seu código-fonte será guardado. Por exemplo, o caminho do módulo pode ser github.com/mymodule. Se você pretende publicar o seu módulo para que outros o usem, o caminho do módulo precisa ser um local do qual as ferramentas do Go consigam baixar o seu módulo. Para saber mais sobre como nomear um módulo com um caminho de módulo, veja Gerenciando dependências.

    Para os fins deste tutorial, use apenas example/hello. 

    $ go mod init example/hello
go: creating new go.mod: module example/hello

  4. No seu editor de texto, crie um arquivo hello.go para escrever o seu código.

  5. Cole o código a seguir no seu arquivo hello.go e salve o arquivo.

    package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

    Este é o seu código em Go. Nele, você:

    • Declara um pacote main (um pacote é uma forma de agrupar funções, formado por todos os arquivos no mesmo diretório).
    • Importa o popular fmt package, que contém funções para formatar texto, incluindo impressão no console. Esse pacote é um dos pacotes da biblioteca padrão que você recebeu ao instalar o Go.
    • Implementa uma função main para imprimir uma mensagem no console. Uma função main é executada por padrão quando você executa o pacote main.

  6. Execute o seu código para ver a saudação.

    $ go run .
Hello, World!

    O comando go run é um dos muitos comandos go que você vai usar para fazer as coisas com Go. Use o comando a seguir para ver a lista dos outros: 

    $ go help

Chamar código de um pacote externo

Quando você precisa que o seu código faça algo que talvez já tenha sido implementado por outra pessoa, você pode procurar um pacote que tenha funções que você possa usar no seu código.

  1. Deixe a mensagem impressa um pouco mais interessante com uma função de um módulo externo.
    1. Acesse pkg.go.dev e pesquise por um pacote "quote".
    2. Nos resultados da pesquisa, localize e clique na v1 do pacote rsc.io/quote (ele deve aparecer com "Other major versions" de rsc.io/quote/v4).
    3. Na seção Documentation, em Index, veja a lista de funções que você pode chamar no seu código. Você vai usar a função Go.
    4. No topo desta página, veja que o pacote quote está incluído no módulo rsc.io/quote.

    Você pode usar o site pkg.go.dev para encontrar módulos publicados cujos pacotes tenham funções que você pode usar no seu próprio código. Os pacotes são publicados em módulos -- como rsc.io/quote -- para que outros possam usá-los. Os módulos são melhorados com novas versões ao longo do tempo, e você pode atualizar o seu código para usar as versões melhoradas.

  2. No seu código em Go, importe o pacote rsc.io/quote e adicione uma chamada à função Go dele.

    Depois de adicionar as linhas destacadas, o seu código deve ficar assim: 

    package main

import "fmt"

import "rsc.io/quote"

func main() {
    fmt.Println(quote.Go())
}
  3. Adicione os novos requisitos e somas de verificação do módulo.

    O Go vai adicionar o módulo quote como requisito, além de um arquivo go.sum usado para autenticar o módulo. Para saber mais, veja Autenticando módulos na Referência de Módulos do Go. 

    $ go mod tidy
go: finding module for package rsc.io/quote
go: found rsc.io/quote in rsc.io/quote v1.5.2
  4. Execute o seu código para ver a mensagem gerada pela função que você está chamando. 
    $ go run .
Don't communicate by sharing memory, share memory by communicating.

    Repare que o seu código chama a função Go, imprimindo uma mensagem engenhosa sobre comunicação.

    Quando você executou go mod tidy, ele localizou e baixou o módulo rsc.io/quote, que contém o pacote que você importou. Por padrão, ele baixou a versão mais recente -- v1.5.2.
