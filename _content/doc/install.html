Baixar

Instalação do Go

Selecione abaixo a aba do sistema operacional do seu computador e, em seguida, siga as instruções de instalação.

  1. Remova qualquer instalação anterior do Go apagando a pasta /usr/local/go (se ela existir) e, em seguida, extraia o arquivo que você acabou de baixar em /usr/local, criando uma árvore nova do Go em /usr/local/go: 
          $ rm -rf /usr/local/go && tar -C /usr/local -xzf go1.14.3.linux-amd64.tar.gz

    (Pode ser necessário executar cada comando separadamente com as permissões necessárias, como root ou usando sudo.)

    Não extraia o arquivo dentro de uma árvore /usr/local/go já existente. Isso é conhecido por produzir instalações do Go quebradas.

  2. Adicione /usr/local/go/bin à variável de ambiente PATH.

    Você pode fazer isso adicionando a seguinte linha ao seu $HOME/.profile ou /etc/profile (para uma instalação em todo o sistema): 

              export PATH=$PATH:/usr/local/go/bin

    Observação: alterações feitas em um arquivo de perfil podem não valer até a próxima vez que você entrar no seu computador. Para aplicar as mudanças imediatamente, basta executar os comandos do shell diretamente ou executá-los a partir do perfil com um comando como source $HOME/.profile.

  3. Adicione $HOME/go/bin (o caminho padrão de binários do Go) à sua variável de ambiente PATH para usar as ferramentas instaladas com go install.

    Você pode fazer isso adicionando a seguinte linha ao seu arquivo $HOME/.profile ou $HOME/.bashrc: 

              export PATH="$PATH:$(go env GOPATH)/bin"
  4. Reinicie quaisquer sessões de terminal abertas para que as mudanças tenham efeito.

  5. Verifique se você instalou o Go abrindo um prompt de comando e digitando o seguinte comando: 
              $ go version
  6. Confirme que o comando exibe a versão instalada do Go.
  1. Abra o arquivo de pacote que você baixou e siga as instruções para instalar o Go.

    O pacote instala a distribuição do Go em /usr/local/go. O pacote adiciona o diretório /usr/local/go/bin à sua variável de ambiente PATH criando um arquivo /etc/paths.d/go.

  2. Adicione $HOME/go/bin (o caminho padrão de binários do Go) à sua variável de ambiente PATH para usar as ferramentas instaladas com go install.

    Você pode fazer isso adicionando a seguinte linha ao seu arquivo ~/.zshrc ou ~/.bash_profile: 

              export PATH="$PATH:$(go env GOPATH)/bin"
  3. Reinicie quaisquer sessões de terminal abertas para que as mudanças tenham efeito.

  4. Verifique se você instalou o Go abrindo uma nova sessão de terminal e digitando o seguinte comando: 
              $ go version
  5. Confirme que o comando exibe a versão instalada do Go.
  1. Abra o arquivo MSI que você baixou e siga as instruções para instalar o Go.

    Por padrão, o instalador instala o Go em Program Files ou Program Files (x86). Você pode mudar o local, se necessário. Depois de instalar, será preciso fechar e reabrir os prompts de comando abertos para que as mudanças no ambiente feitas pelo instalador sejam refletidas no prompt de comando.

  2. Verifique se você instalou o Go.
    1. No Windows, clique no menu Iniciar.
    2. Na caixa de pesquisa do menu, digite cmd e, em seguida, pressione a tecla Enter.
    3. Na janela do Prompt de Comando que aparecer, digite o seguinte comando: 
                    $ go version
    4. Confirme que o comando exibe a versão instalada do Go.
