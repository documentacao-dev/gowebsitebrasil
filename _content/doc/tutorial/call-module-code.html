Na seção anterior, você criou um módulo greetings. Nesta seção, você vai escrever código que chama a função Hello do módulo que acabou de escrever. Você vai escrever código que pode ser executado como uma aplicação e que chama o código do módulo greetings.

Observação: Este tópico faz parte de um tutorial em várias partes que começa com Criar um módulo Go.
  1. Crie um diretório hello para o código-fonte do seu módulo Go. É aqui que você vai escrever o código que chama o módulo.

    Depois de criar este diretório, você deve ter os diretórios hello e greetings no mesmo nível da hierarquia, assim: 

    <home>/
 |-- greetings/
 |-- hello/

    Por exemplo, se o seu prompt de comando estiver no diretório greetings, você pode usar os seguintes comandos: 

    cd ..
mkdir hello
cd hello
  2. Habilite o rastreamento de dependências para o código que você está prestes a escrever.

    Para habilitar o rastreamento de dependências do seu código, execute o comando go mod init, passando o nome do módulo em que o seu código vai estar.

    Para este tutorial, use example.com/hello como caminho do módulo. 

    $ go mod init example.com/hello
go: creating new go.mod: module example.com/hello
  3. No seu editor de texto, dentro do diretório hello, crie um arquivo para escrever o seu código e chame-o de hello.go.
  4. Escreva código para chamar a função Hello e, em seguida, imprimir o valor de retorno da função.

    Para isso, cole o código a seguir em hello.go. 

    package main

import (
    "fmt"

    "example.com/greetings"
)

func main() {
    // Get a greeting message and print it.
    message := greetings.Hello("Gladys")
    fmt.Println(message)
}

    Neste código, você:

    • Declara um pacote main. Em Go, código executado como uma aplicação precisa estar em um pacote main.
    • Importa dois pacotes: example.com/greetings e o pacote fmt. Isso dá ao seu código acesso às funções desses pacotes. Importar example.com/greetings (o pacote contido no módulo que você criou antes) dá acesso à função Hello. Você também importa fmt, com funções para tratar entrada e saída de texto (como imprimir texto no console).
    • Obtém uma saudação chamando a função Hello do pacote greetings.
  5. Edite o módulo example.com/hello para usar o seu módulo local example.com/greetings.

    Em um uso de produção, você publicaria o módulo example.com/greetings a partir do seu repositório (com um caminho de módulo que reflita o local de publicação), onde as ferramentas do Go poderiam encontrá-lo para baixá-lo. Por enquanto, como você ainda não publicou o módulo, precisa adaptar o módulo example.com/hello para que ele consiga encontrar o código de example.com/greetings no seu sistema de arquivos local.

    Para isso, use o comando go mod edit para editar o módulo example.com/hello e redirecionar as ferramentas do Go, do caminho do módulo (onde o módulo não está) para o diretório local (onde ele está).

    1. No prompt de comando, dentro do diretório hello, execute o seguinte comando: 
      $ go mod edit -replace example.com/greetings=../greetings

      O comando especifica que example.com/greetings deve ser substituído por ../greetings para fins de localização da dependência. Depois de executar o comando, o arquivo go.mod no diretório hello deve incluir uma diretiva replace: 

      module example.com/hello

go 1.16

replace example.com/greetings => ../greetings
    2. No prompt de comando, dentro do diretório hello, execute o comando go mod tidy para sincronizar as dependências do módulo example.com/hello, adicionando as que o código exige, mas que ainda não estão rastreadas no módulo. 
      $ go mod tidy
go: found example.com/greetings in example.com/greetings v0.0.0-00010101000000-000000000000

      Depois que o comando terminar, o arquivo go.mod do módulo example.com/hello deve ficar assim: 

      module example.com/hello

go 1.16

replace example.com/greetings => ../greetings

require example.com/greetings v0.0.0-00010101000000-000000000000

      O comando encontrou o código local no diretório greetings e então adicionou uma diretiva require para especificar que example.com/hello requer example.com/greetings. Você criou essa dependência quando importou o pacote greetings em hello.go.

      O número após o caminho do módulo é um número de pseudo-versão -- um número gerado usado no lugar de um número de versão semântica (que o módulo ainda não tem).

      Para referenciar um módulo publicado, um arquivo go.mod normalmente omite a diretiva replace e usa uma diretiva require com um número de versão marcado no final. 

      require example.com/greetings v1.1.0

      Para saber mais sobre números de versão, veja Numeração de versões de módulos.

  6. No prompt de comando, dentro do diretório hello, execute o seu código para confirmar que ele funciona. 
    $ go run .
Hi, Gladys. Welcome!

Parabéns! Você escreveu dois módulos funcionando.
