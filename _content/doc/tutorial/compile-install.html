Neste último tópico, você vai aprender alguns comandos novos do go. Embora o comando go run seja um atalho útil para compilar e executar um programa quando você faz alterações com frequência, ele não gera um executável binário.

Este tópico apresenta dois comandos adicionais para compilar código:

  • O comando go build compila os pacotes, junto com as dependências deles, mas não instala o resultado.
  • O comando go install compila e instala os pacotes.
Observação: Este tópico faz parte de um tutorial em várias partes que começa com Criar um módulo Go.
  1. No terminal, dentro da pasta hello, execute o comando go build para compilar o código em um executável. 
    $ go build
  2. No terminal, dentro da pasta hello, execute o novo executável hello para confirmar que o código funciona.

    Observe que o resultado pode ser diferente dependendo de você ter alterado o código de greetings.go depois de testá-lo.

    • No Linux ou Mac: 
      $ ./hello
map[Darrin:Great to see you, Darrin! Gladys:Hail, Gladys! Well met! Samantha:Hail, Samantha! Well met!]
    • No Windows: 
      $ hello.exe
map[Darrin:Great to see you, Darrin! Gladys:Hail, Gladys! Well met! Samantha:Hail, Samantha! Well met!]

    Você compilou a aplicação em um executável, então já pode rodá-la. Mas, do jeito que está, para executá-la o terminal precisa estar na pasta do executável, ou você precisa informar o caminho até ele.

    Em seguida, você vai instalar o executável para poder rodá-lo sem informar o caminho.

  3. Descubra o caminho de instalação do Go, para onde o comando go vai instalar o pacote atual.

    Você pode descobrir o caminho de instalação executando o comando go list, como no exemplo a seguir: 

    $ go list -f '{{.Target}}'

    Por exemplo, a saída do comando pode ser /home/gopher/bin/hello, o que significa que os binários são instalados em /home/gopher/bin. Você vai precisar desse diretório de instalação no próximo passo.

  4. Adicione o diretório de instalação do Go ao PATH do shell do sistema.

    Assim, você poderá executar o executável do seu programa sem precisar informar onde ele está.

    • No Linux ou Mac, execute o seguinte comando: 
      $ export PATH=$PATH:/path/to/your/install/directory
    • No Windows, execute o seguinte comando: 
      $ set PATH=%PATH%;C:\path\to\your\install\directory

    Como alternativa, se você já tiver um diretório como $HOME/bin no PATH do shell e quiser instalar seus programas Go ali, pode mudar o destino da instalação definindo a variável GOBIN com o comando go env: 

    $ go env -w GOBIN=/path/to/your/bin

    ou 

    $ go env -w GOBIN=C:\path\to\your\bin
  5. Depois de atualizar o PATH, execute o comando go install para compilar e instalar o pacote. 
    $ go install
  6. Execute sua aplicação simplesmente digitando o nome dela. Para deixar isso mais interessante, abra um novo prompt de comando e execute o executável hello em outra pasta qualquer. 
    $ hello
map[Darrin:Hail, Darrin! Well met! Gladys:Great to see you, Gladys! Samantha:Hail, Samantha! Well met!]

Isso encerra este tutorial de Go!
