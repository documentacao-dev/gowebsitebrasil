A linguagem de programação Go é um projeto de código aberto para tornar os programadores mais produtivos.

Go é expressiva, concisa, limpa e eficiente. Seus mecanismos de concorrência facilitam escrever programas que aproveitam ao máximo máquinas multicore e em rede, enquanto seu sistema de tipos inovador permite construir programas flexíveis e modulares. Go compila rapidamente para código de máquina, mas tem a conveniência do coletor de lixo e o poder da reflexão em tempo de execução. É uma linguagem compilada, de tipagem estática e rápida, que tem a sensação de uma linguagem interpretada de tipagem dinâmica.

Acessando bancos de dados relacionais

Uma visão geral dos recursos de acesso a dados do Go.

Abrindo um handle de banco de dados

Você usa o handle de banco de dados do Go para executar operações no banco. Depois de abrir um handle com as propriedades de conexão, ele representa um pool de conexões que é gerenciado em seu nome.

Executando instruções SQL que não retornam dados

Para operações SQL que podem alterar o banco, incluindo INSERT, UPDATE e DELETE do SQL, você usa os métodos Exec.

Consultando dados

Para instruções SELECT que retornam dados de uma consulta, use o método Query ou QueryRow.

Usando prepared statements

Definir um prepared statement para uso repetido pode fazer seu código rodar um pouco mais rápido, evitando o custo de recriar a instrução a cada vez que o código executa a operação no banco.

Executando transações

sql.Tx exporta métodos que representam a semântica específica de transações, incluindo Commit e Rollback, além dos métodos que você usa para executar operações comuns no banco.

Cancelando operações de banco de dados em andamento

Usando context.Context, você pode fazer com que as chamadas de função e os serviços da sua aplicação parem antes e retornem um erro quando o processamento não for mais necessário.

Gerenciando conexões

Em alguns programas avançados, você pode precisar ajustar os parâmetros do pool de conexões ou trabalhar com as conexões explicitamente.

Evitando o risco de SQL injection

Você pode evitar o risco de SQL injection passando os valores dos parâmetros SQL como argumentos das funções do pacote sql

Desenvolvendo uma atualização de versão maior

Uma atualização de versão maior pode ser muito disruptiva para os usuários do seu módulo, porque inclui mudanças incompatíveis e representa um novo módulo. Saiba mais neste tópico.

Publicando um módulo

Quando você quer disponibilizar um módulo para outros desenvolvedores, você o publica para que ele fique visível para as ferramentas do Go. Depois de publicar o módulo, os desenvolvedores que importarem seus pacotes conseguirão resolver a dependência do módulo executando comandos como go get.

Numeração de versões de módulos

O desenvolvedor do módulo usa cada parte do número de versão para sinalizar a estabilidade e a compatibilidade retroativa da versão. A cada nova release, o número de versão reflete especificamente a natureza das mudanças no módulo desde a release anterior.

Código que cresce com elegância

Um dos principais objetivos de design do Go é a adaptabilidade do código: deve ser fácil pegar um design simples e construir sobre ele de forma limpa e natural. Nesta palestra, Andrew Gerrand descreve um servidor simples de "roleta de chat" que pareia conexões TCP recebidas e, em seguida, usa os mecanismos de concorrência, as interfaces e a biblioteca padrão do Go para estendê-lo com uma interface web e outros recursos. Embora a função do programa mude drasticamente, a flexibilidade do Go preserva o design original enquanto ele cresce.

Padrões de concorrência em Go

Concorrência é a chave para projetar serviços de rede de alta performance. As primitivas de concorrência do Go (goroutines e channels) oferecem uma forma simples e eficiente de expressar execução concorrente. Nesta palestra, vemos como problemas complicados de concorrência podem ser resolvidos com elegância usando código Go simples.
